2 JSON and JSON Schema
Consider data about births: for each month of a year, we record the number of male,
female, and total births. The file births.json stores these observations as a JSON array,
with one object per month.
2.1 Docker Environment
The directory LabSession9/ contains a Dockerfile that installs the command-line
tools used in the first part of this sheet, together with the data files births.json and
births_schema.json. Build the image and start a temporary interactive container:

user@host$ cd LabSession9
