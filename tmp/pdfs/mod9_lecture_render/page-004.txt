6. There are different approaches to ensure that an LLM follows a certain output structure.
Match a technique name to each description.
Technique Name Description
Show the model correctly formatted outputs so it imitates
the format. Simple, but no guarantee.
Supply the output skeleton yourself (e.g. the JSON keys
and braces) and let the model generate only the values
it does not know beforehand. The scaffolding cannot be
malformed because the model never emits it.
Restrict generation to tokens allowed by a gram-
mar/schema, so the output is valid by construction.
Validate the output (e.g. against a JSON Schema); on
failure, re-prompt or ask another tool/model to repair it.
